
# Employee Management System - Oracle SQL & PL/SQL

## Project Overview

Employee Management System is a database project developed using Oracle SQL and PL/SQL.

The project manages employee information such as employee details, departments, job roles, and salaries.

It demonstrates practical SQL queries, table relationships, JOINs, aggregate functions, subqueries, and PL/SQL programming concepts.
